# You Don't Know JS Yet — Tradução PT-BR

Tradução para português do Brasil da série *You Don't Know JS Yet* (2ª edição), de Kyle Simpson.

## Livros traduzidos

* [Livro 1: Get Started](get-started/README.md) — O que é JavaScript, panorama da linguagem, as raízes do JS e o quadro geral.
* [Livro 2: Scope & Closures](scope-closures/README.md) — Escopo léxico, escopo global, hoisting, TDZ, closures e o padrão de módulo.

## Observações sobre a tradução

* O código dos exemplos foi mantido em inglês (identificadores, strings e saídas), preservando a fidelidade ao original; apenas os comentários explicativos dentro do código foram traduzidos.
* Termos técnicos consagrados em inglês foram mantidos quando a tradução prejudicaria o entendimento: *closure*, *hoisting*, *scope* (escopo), *shadowing* (sombreamento), IIFE, TDZ, *getter/setter*, *callback*, entre outros.
* As imagens apontam para os arquivos originais em `get-started/images/` e `scope-closures/images/`, evitando duplicação de arquivos no repositório.
* O prefácio geral da série (`preface.md`) ainda não foi traduzido; os links apontam para a versão em inglês.
